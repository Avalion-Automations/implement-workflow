# Documentation work tracking

Each documentation agent starts from [the goal template](goal-template.md) and finishes with [the result handoff template](result-handoff-template.md). Store one filled goal and one filled result handoff per scoped work item in the delivery owner's tracker; do not treat a chat-only update as a handoff.

The goal records the intended outcome, scope, acceptance checks, dependencies, and explicit non-goals. The result handoff records changed paths, verification evidence, remaining blockers/risks, and exact promotion status. A promotion handoff must state the canonical version and SHA-256 from `docs/manifest.yaml`.
